# sonal-ssj.github.io

Personal academic website of **Sonal Joshi** — AI Safety & Evaluations researcher,
Postdoctoral Fellow at the Center for Language and Speech Processing, Johns Hopkins University.

🔗 **Live:** https://sonal-ssj.github.io

## Run locally

```bash
docker compose up        # serves at http://localhost:8080
docker compose down      # stop and free the port
```

## Structure

- `_pages/` — site pages (about, projects, publications, CV)
- `_projects/` — project cards
- `_news/` — news / announcements
- `_bibliography/papers.bib` — publications
- `_data/` — socials, CV, repositories, coauthors
